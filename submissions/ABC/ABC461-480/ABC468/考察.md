C問題

[N = 10]

N! < 10^7

順列全探索
順列の全パターン数 N! 通り
順列の長さ N

* 順列の全パターンを生成する
C++ では、std::next_permutation();

* それぞれの順列 A について、辞書順で
A > P && A < Q を判定する

* 辞書順の大小判定とは
    * S = 1, 2, 3
      T = 1, 2, 3, 4, 5
      -> S < T
    * S = 1, 2, 3, 4, 5, 6
      T = 1, 2, 3, 5, 5, 7, 7
      -> S < T

* どう実装する？
長さ N 
for(int i=0; i < N; ++i){
    S[i] == T[i] ならば continue;
    S[i] != T[i] ならば
        S[i] < T[i] ならば　S < T, break
        S[i] > T[i] ならば　S > T, break
}

ひとつの順列について、判定にかかる時間 O(N)
順列の最大パターン数　N! 通り
全体の最悪計算量 O(N * N!) 


## E問題

取りうる範囲が絞れる
$1 \leq r-l+1 \leq N$
意味することは、平均をとる区間の長さは1~N

$\frac{1}{r-l+1}$でまとめたい

区間の長さを固定したときの$A_i$それぞれの寄与（出現回数）を調べる
