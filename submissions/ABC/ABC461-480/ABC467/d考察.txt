四点 P, Q, R, S
* C1 の中心は二点 P, Q の垂直二等分線上に存在する
* C2 の中心は二点 R, S の垂直二等分線上に存在する
* これら二つの垂直二等分線が共有点を持つ

垂直二等分線を式で表す
直線の式: ax + by + c = 0

直線(1)
二点 P, Q の垂直二等分線上の点のひとつを 点A = (x, y) とおく
(AP間の距離) = (AQ間の距離)
...式変形
a1: -2Px + 2Qx
b1: -2Py + 2Qy
c1: Px^2 + Py^2 - Qx^2 - Qy^2

直線(2)
a2, b2, c2 が求まる

これらの二直線の関係
傾きが異なる場合（並行でない場合）
    -> 共有点が必ず存在します

直線の傾き
ax + by + c = 0
傾き：-a/b (b != 0のとき)

二直線の傾きの関係
-a1 / b1 ><? -a2 / b2
a1 * b2 ><? a2 * b1

二直線の傾きが異なる
a1 * b2 != a2 * b1

二直線の傾きが等しいとき
a1 * b2 == a2 * b1 のとき
二直線が重なるか、そうでないか

アプローチ１
係数比較
    a1 * x + b1 * y + c1 = 0
    a2 * x + b2 * y + c2 = 0
    a1 = k * a2 かつ b1 = k * b2 かつ c1 = k * c2
    を満たす実数 k が存在する
    k = a1 / a2
    このとき
    b1 = k * b2 かつ c1 = k * c2 を満たすならば二直線は一致する
    
ただし、これを実際にやろうとすると、オーバーフロー
もしくは浮動小数点数の誤差によるWAの可能性がある
    c1 = k * c2 
    c1 = a1 / a2 * c2

    c1 * a2 = a1 * c2
    c1 * a2 という値の取りうる範囲は?
    c1: Px^2 + Py^2 - Qx^2 - Qy^2 ... O(10^18)
    a2: -2Rx + 2Sx                ... O(10^9)
    -> c1 * a2 .. O(10^27)
    符号付き64bit整数の取れる値の最大値は約 9 * 10^18
    なのでオーバーフローが起こりうる
    -> 別の方法を考える

アプローチ2
二直線が一致する
二点 R, S の中点を N とおいたときに
点 N は、直線(1)上の点である

a1: -2Px + 2Qx
b1: -2Py + 2Qy
c1: Px^2 + Py^2 - Qx^2 - Qy^2

Nx: (Rx + Sx) / 2 ... O(10^9)
Ny: (Ry + Sy) / 2

a1 * Nx + b1 * Ny + c1 == 0 なら、二直線は一致する
(-2Px + 2Qx) * (Rx + Sx) / 2
= (-Px + Qx) * (Rx + Sx)

a1: -Px + Qx
b1: -Py + Qy
Nx: Rx + Sx
Ny: Ry + Sy
