多項式演算について
A(x) = sum_{i=0}^{I} a_i*x^i
B(x) = sum_{j=0}^{J} a_j*x^j
A(x)*B(x) = sum_{k=0}^{I+J} ( sum_{l=0}^{k} (a_l*x^l)*(b_(k-l)*x^(k-l)) )
          = sum_{k=0}^{I+J} ( sum_{l=0}^{k} (a_l*b_(k-l))*x^k )
[x^k]A(x)B(x) = sum_{l=0}^{k} a_l*b_(k-l)

これは畳み込み演算と等価

W_n = cos(-2pi/n) + isin(-2pi/n) として
DFT行列 F_n = { f_n_(i,j) } = { (W_n)^(i*j) }
ただし 0 <= i,j <= n-1
IDFT行列 F_n* = { f_n*_(i,j) } = { (W_n)^(-i*j) }
F_n * F_n* = n * I
ただし I は単位行列

C(x) = A(x)B(x) に対して
X(x) の係数行列を x_ として
a_ = [a_0,...,a_(n-1)]^T
b_ = [b_0,...,b_(n-1)]^T
c_ = [c_0,...,c_(n-1)]^T

DFT 離散フーリエ変換
F_n*a_ = [A((W_n)^0),...,A((W_n)^i),...,A((W_n)^(n-1))]^T
A((W_n)^i) = sum_{j=0}^{n-1} a_j*(W_n)^(i*j)

IDFT a_ = 1/n * F_n* * F_n*a_

C((W_n)^i) = A((W_n)^i)B((W_n)^i)

NTT 数論変換
W_n は，n 乗して初めて 1 になる数であればよい

回転子を (3^119)^16 とすれば，524287 次多項式までに対して同じことが行える
